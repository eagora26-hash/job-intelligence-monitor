# Fiverr Gig Description

## Title
I will build a job monitoring bot with Telegram alerts and a live analytics dashboard

## Short description (URL/preview text)
Custom multi-site monitoring system: scrapes job boards & marketplaces 24/7, scores
opportunities by your keywords, alerts you on Telegram for new matches only, with a live
dashboard and Excel/CSV export.

## Long description

**Stop refreshing job boards. Get pinged the moment your kind of work appears.**

I build production-grade monitoring systems that watch multiple websites around the clock
and tell you — instantly, on Telegram — when something matching *your* keywords shows up.
Never the same item twice, never a flood: the system builds a baseline first, then alerts
only on genuinely new opportunities.

You also get a professional live dashboard: searchable results, trend charts, skill-demand
analytics, source health monitoring, and one-click CSV / Excel / JSON export.

**This gig is based on a real product I built and run** — a 5-source job-intelligence
platform (RemoteOK, We Work Remotely, Freelancer, Fiverr, Wellfound) with 65 automated
tests, CI/CD, Docker, and free-tier cloud deployment. Ask for the live demo link and the
GitHub repository.

It works for anything, not just jobs: price tracking, tender/RFP feeds, real-estate
listings, competitor monitoring.

## Key features
- Multi-site scraping (APIs, RSS, JS pages — anti-bot aware via TLS fingerprinting)
- Keyword relevance scoring + auto-categorization + skill extraction
- Telegram alerts: baseline first, then **new items only**, never duplicates
- Live analytics dashboard (trends, heatmaps, leaderboards, search)
- CSV / Excel / JSON export
- Runs free 24/7 (GitHub Actions + Streamlit Cloud) or on your server (Docker)
- Clean, tested, documented code — you own everything

## Deliverables
- Full source code in your GitHub repository
- Deployed dashboard (free hosting) + scheduled scraping configured
- Telegram bot wired to your chat
- Installation, user and admin guides (written for non-developers)
- 14-day post-delivery support for fixes

## Ideal clients
Freelancers who want first-responder advantage on marketplaces · agencies needing a lead
pipeline · recruiters tracking demand · anyone who needs "watch these sites and tell me
when X appears".
