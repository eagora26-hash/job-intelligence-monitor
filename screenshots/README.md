# Screenshots

Placeholder directory for portfolio screenshots referenced by the main
[README](../README.md). Capture these once the dashboard is running with data
(`python generate_demo_data.py` then `streamlit run job_monitor/dashboard/app.py`).

| File | What to capture |
|---|---|
| `01_overview.png` | **Dashboard Overview** — KPI metrics row + "Jobs by source" pie + latest-jobs table |
| `02_analytics.png` | **Analytics page** — daily trend, jobs-by-source/category bars, top-skills chart |
| `03_explorer.png` | **Job Explorer** — search + filters applied, results table, CSV/Excel export buttons |
| `04_health.png` | **Source Health & Observability** — per-source status cards + system metrics |
| `05_telegram.png` | **Telegram Notification** — a "🚀 NEW JOB" alert on a phone/desktop |
| `06_database.png` | **Database Overview** — e.g. `sqlite3 database/jobs.db ".schema"` or a DB browser view |

Suggested capture settings: 1440×900, light theme, browser zoom 100%. Keep file sizes < 500 KB
(PNG, optimized) so the README loads quickly on GitHub.
